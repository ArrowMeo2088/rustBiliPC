## 约定

- `ref/` 不入库，所以任何从参考仓库读出的结论**必须抄进 docs**，否则换机器就丢失了。
- 改代码同步改文档：涉及机制的改动更新 architecture.md，涉及接口/选项的改动更新 api-notes.md，
  并更新所在目录的 README。
- 阶段状态只在 architecture.md 的阶段表里维护，不散落到别处。
