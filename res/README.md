# res — 资源文件

存放图标、字体、图片、主题等运行时资源。

- 本目录默认**不提交 git**（`/res/*`），**唯一的例外是 `icon.ico`**：它是构建输入
  （`build.rs` 把它链进 Windows 产物），CI 上没有它就等于产物没图标，所以必须入库。
  别的资源要随仓库分发，先与项目负责人确认再调 `.gitignore`。
- 资源在被代码引用后，请在此登记：文件名、用途、来源/许可证。

| 文件 | 用途 | 来源/许可证 |
| ---- | ---- | ----------- |
| `icon.ico` | 程序图标（exe / 快捷方式 / 窗口与任务栏那颗走 gpui 的 `load_icon()`，见架构文档第 4.30 节）。7 幅：16/24/32/48/64/128/256，32 bpp，144,167 字节 | 用户提供（2026-10-27） |
